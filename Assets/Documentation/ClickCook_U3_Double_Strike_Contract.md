# U3 — додатковий удар

ADOPTED IMPLEMENTATION CONTRACT — 2026-10-24. Джерела: node manifest і proposal §12.3. Числа нижче — початковий баланс ClickCook, не source rewards і не результат pacing playtest. Працюють лише перші вузли chance/power.

- `node.double_strike_chance.01` / «Подвійний рух I»: prerequisite `node.click_strength.01:2`, 10 рангів, шанс `0.02N` (0–20%), ціна `ceil(350 × 1.7^N)`.
- `node.double_strike_power.01` / «Відточений повтор I»: prerequisite `node.double_strike_chance.01:1`, 10 рангів, відносна сила `q = 0.5 + 0.05N` (×0.5 без покупки, ×0.55 після першої, ×1 при N=10), ціна `ceil(400 × 1.7^N)`. Сила сама не відкриває шанс. N — вже придбаний ранг конкретного вузла; decimal ціни округлюються вгору лише наприкінці.
- Один прийнятий trigger (manual click, Enter або початковий/повторний Hold) застосовує первинний удар. Якщо страва жива, ненульовий double chance дає один незалежний proc roll `u < chance`, u∈[0,1). Успіх застосовує рівно один додатковий удар по тому самому order; він не породжує proc. Якщо первинний удар завершив order, proc roll і додатковий крит не споживаються. Шанс 0 не споживає proc RNG, відхилений trigger не споживає жодного combat RNG.
- Кожний фактичний удар має окремий crit roll. Порядок: primary crit → primary damage → за наявності HP proc roll → extra crit → extra damage. Звичайна сила D — чинний ClickDamage; первинний damage `ceil(D × (critical ? M : 1))`, додатковий `ceil(D × q × (critical ? M : 1))`. Одна стеля після всіх множників: D=6, q=.55, M=2.1 дають 4 звичайного або 7 критичного damage повтору. Жодного повторного округлення бази повтору.
- HP обмежується нулем після кожного удару. Completion/receipt/XP/payout/NotifyChanged відбуваються один раз після bounded transaction; зайві damage/удари не переходять на наступну страву. Hold скасовується при completion. Пауза/Back/result/застарілий pointer/очікуваний інший order зберігають чинні guards.
- Feedback одного trigger: LastStrikeCount 1/2, LastExtraStrikeDamage — сила повтору, LastHitDamage — сума розрахованого damage фактичних ударів до HP clamp, LastHitWasCritical — хоча б один удар критичний. На новому trigger/виборі/Back feedback очищується. UI показує факт двох рухів і сумарний damage, фактичні chance/q у статистиці; залишок звичайних кліків позначений верхньою оцінкою без бонусів.
- Купівля через чинні node quotes між днями, з cap/replay/pause/коштовими guards й автозбереженням. Schema 5 додає обидва canonical nodeId, 0–10 з purchased prerequisites. Schema 1–4 не приймають цих IDs навіть при rank 0. Старі wallet/XP/ранги зберігаються без eager rewrite; Save пише 5, старі backups читаються, >5 захищено. Transient feedback/gesture не зберігаються.
- Наступні double tiers і triple залишаються недоступними. U3b визначить спільний розподіл double/triple до продажу triple, з максимумом трьох фактичних ударів. Auto до цього proc не підключено.
