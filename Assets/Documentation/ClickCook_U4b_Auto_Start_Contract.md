# U4b — стартова дія помічника

ADOPTED IMPLEMENTATION CONTRACT — 2026-10-25. Manifest: `node.auto_action_chance.01` / «Пильний помічник I», prerequisite `node.click_strength.01:2`. Власні 10 рангів, шанс `.02N` до 20%; ціна `ceil(250 × 1.8^N)` у decimal, одне кінцеве округлення вгору. Початковий баланс ClickCook, не source rewards/доведений pacing.

- Один roll лише при першому фактичному вході в cooking конкретного order instance. Guard приймає тільки чинний активний order/день без паузи. Позначка `AutoStartChecked` ставиться перед roll, включно з шансом 0 і промахом; шанс 0 не споживає RNG. Успіх `u < chance`, u∈[0,1), застосовує один негайний звичайний auto batch.
- Без періодичного авто batch — одна дія по 1 HP. З U4a action_count — `1+N` дій по 1 HP. Спільний ApplyAutoBatch: без критів/double/triple, зупинка на HP=0, одна нагорода/XP/NotifyChanged, без carry й автоматичного вибору наступного order. Chance не вмикає періодичний timer; стартовий batch не замінює/не прискорює його перший повний секундний інтервал.
- Back зберігає checked-позначку на самому order: повторний вибір того самого order не дає нового roll після успіху чи промаху. Чинне правило Back скидає HP-прогрес, включно зі стартовою дією, але не право на новий roll. Інший order, навіть з тією самою стравою/слотом після replacement, має власну позначку. Pause/focus/disable/timer reset не скидають її. Невдалий/paused/foreign-order виклик не споживає право першого входу.
- Controller викликає start після прийнятого вибору й переходу на cooking. Lethal старт одразу показує чинний result screen. HP feedback використовує «Помічник», незалежно від джерела batch; manual trigger очищує auto feedback. Detail показує шанс, поточний batch і правило першого входу; статистика розрізняє періодичний цикл та стартовий шанс у тих самих шести рядках.
- Schema 8 додає тільки canonical ID auto_action_chance.01, rank 0–10 з purchased prerequisite. Schema 1–7 відхиляють цей ID навіть при rank 0; старі wallet/XP/ранги/backup читаються без eager rewrite чи free chance. Save пише 8, >8 захищено. Order/checked/timer не зберігаються: після restart незавершений день як і раніше скидається, нові orders мають нові права першого входу без додаткової виплати за старі.
- Наступні chance tiers недоступні. Наступний slice U4c — перша auto_strength; multiplier/frequency окремо, U4 ще не завершено.

Локальні ризики: повторний roll на Back/промаху, combat RNG чи неправильний batch, негайне completion до показу cooking, зайвий ранній periodic tick, втрата старих ranks/schema, обрізаний рядок статистики.
